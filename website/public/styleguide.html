Foundations

Motion — Scroll Reveal

The standard report/section entrance. Add a utility class; an IntersectionObserver adds .visible when the element scrolls in. Children inside .pills/.cards/.checklist stagger by 0.08s. Always ship with the reduced-motion + print guards.

Reveal utilities

.fade-in / .slide-left / .slide-right / .scale-in

Four entrance directions. Initial state is hidden; .visible resets to neutral.

fade-in ↑
slide-left →
slide-right ←
scale-in ⤢
Duration
.7s (fade/slide), .6s (scale)
Easing
cubic-bezier(.4,0,.2,1)
Trigger
IntersectionObserver, threshold .15, rootMargin 0 0 -40px 0
Stagger
idx*0.08s inside .pills/.cards/.checklist
Toggle
.visible → opacity 1, transform none

Required guards: @media (prefers-reduced-motion:reduce) and @media print both force opacity 1 / transform none so content is never hidden when motion is off or on paper.
