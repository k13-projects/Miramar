Live Instagram Feed

Connected the Behold.so widget for a live Instagram feed that auto-updates with posts from @miramarfoodhall. Styled with an edge-to-edge responsive layout.

Integration CSS

Accessibility & Visual QA

Deep ADA/WCAG AA compliance pass. Added skip-to-content link, ARIA labels, focus-visible states, improved contrast ratios, and keyboard support throughout the entire site.

Site Performance & Vendor Card UI

Compressed all 13 vendor images from 50 MB to 1.8 MB (96% reduction). Converted PNGs to JPGs. Added GPU-accelerated transitions, RAF-throttled scroll handlers, and redesigned vendor Instagram links for better UX.

Performance Images CSS
23 files changed, 50 MB saved
